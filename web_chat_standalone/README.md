# خادم محادثة الويب الخاص

هذا مستودع جاهز لغرفة محادثة عامة تعمل بتقنيات الويب النقية (HTML/CSS/JS) ومتصلة بقاعدة بيانات (Supabase).

## الميزات
- تصميم زجاجي (Glassmorphism) مذهل.
- ألوان متدرجة ومتحركة.
- اتصال فوري (Real-time) بقاعدة البيانات بدون تأخير.
- دعم رفع الصور مع المعاينة.

## النشر على Netlify
هذا المشروع لا يحتاج إلى أي أدوات بناء (Build tools) مثل Node.js أو Webpack.
كل ما تحتاجه هو:
1. رفع هذا المستودع على حسابك في GitHub.
2. الدخول إلى موقع [Netlify](https://www.netlify.com/).
3. النقر على "Add new site" ثم "Import an existing project".
4. اختيار المستودع الخاص بك من GitHub.
5. في إعدادات البناء (Build settings)، اترك حقلي `Build command` و `Publish directory` فارغين (أو اكتب `.` في حقل مسار النشر).
6. اضغط على Deploy Site وستحصل على رابط موقعك خلال ثوانٍ!

## قاعدة البيانات
هذا الموقع يتصل بخدمات Supabase، وتم إعداد الجداول وقواعد التخزين اللازمة للعمل بسلاسة.
